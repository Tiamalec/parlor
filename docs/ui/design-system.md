# V2 UI Design System

状态：已确认，作为 PySide6 V2 客户端后续 UI 工作的视觉基线。Legacy 客户端与服务端管理台不在本规范的实现范围内。

## 1. 设计原则

1. 安静、现代、可靠，优先保障长时间聊天和任务扫描的可读性。
2. 使用少量连续表面层级，不用深浅底板拼接制造层级。
3. 卡片只用于独立对象或浮层；列表优先使用行、分隔线和选中态。
4. 蓝色表示主要操作与选择，紫色只表示 AI/Agent 语义。
5. 所有状态同时使用文字与形状/图标，颜色不作为唯一信息载体。

## 3. 表面层级

- `canvas`：页面背景，不放边框或阴影。
- `surface`：聊天主区、会话栏、输入区、设置分组。相邻 surface 优先用 1px 分隔线，不套多层卡片。
- `surface_subtle`：hover、选中、表头和局部分组，不作为大面积独立底板。
- `surface_elevated`：菜单、对话框、详情浮层。Qt QSS 不支持可靠的 `box-shadow`，默认使用强边框；只在必要浮层使用一次轻量 `QGraphicsDropShadowEffect`。
- `overlay_scrim`：只用于模态/抽屉，不改变底层业务状态。

`QScrollArea`、其 viewport 与内容 QWidget 必须声明同一表面角色，禁止依赖系统 palette 或透明背景偶然透出父组件。

## 4. 字体与图标

使用操作系统 UI 字体，不捆绑新字体。中文由系统字体回退处理。

| 层级 | 大小 | 字重 | 用途 |
| --- | ---: | ---: | --- |
| Page title | 20px | 700 | 页面标题 |
| Section title | 16px | 600 | 分组标题、聊天标题 |
| Body | 14px | 400 | 正文、输入内容 |
| Body strong | 14px | 600 | 列表主标题、按钮 |
| Caption | 12px | 400 | 辅助信息、状态 |
| Micro | 11px | 400 | 仅时间戳等非关键元数据 |

图标使用精选 Lucide SVG：导航 20px，工具栏 18px，行内状态 16px，小型辅助 14px。默认描边宽度保持 Lucide 原值；同一按钮内不混用 Emoji 与 SVG。

## 5. 尺寸、间距与圆角

- 间距标尺：4、8、12、16、20、24、32px。
- 页面外边距：标准 24px，紧凑窗口 16px。
- 控件高度：紧凑 32px，默认 36px；导航项 56px。
- 列表行：通讯录 48px、任务 60px、会话 64px。
- 圆角：小型元素 6px、控件 8px、面板/消息 10px、弹窗/浮层 12px。
- 不新增 14px 以上的大圆角容器；头像例外，保持圆形。
- 边框统一 1px；焦点态使用 2px `primary` 边界并保证控件外尺寸稳定。

## 6. 交互状态

所有可交互控件必须定义：default、hover、pressed、focus-visible、checked/selected、disabled、error。

- 选中项使用背景 + 文字/图标变化；导航额外保留稳定的形状指示。
- 危险操作使用 `danger` 文字/边框，确认按钮才使用实色危险背景。
- 状态徽标必须包含文本，不使用纯色圆点作为唯一状态。
- 图标按钮必须有 tooltip、accessible name 和键盘焦点。

## 7. 布局与密度

| 宽度 | 布局 |
| --- | --- |
| `720–759` | 紧凑模式；64px 导航；聊天会话栏隐藏并提供返回/列表入口；详情为覆盖层 |
| `760–1099` | 72px 导航；页面 16px 边距；会话栏按可用空间显示；详情为覆盖层 |
| `1100–1279` | 76px 导航；会话栏约 300–320px；详情仍优先覆盖，避免压缩聊天正文 |
| `≥1280` | 76px 导航；会话栏 320px；聊天正文满足最小宽度时详情可停靠 |

设置内容最大宽度 760px；AI 任务列表最大内容宽度 1100px。通讯录保持左侧目录 + 右侧详情，但不将空详情包装成巨大卡片。

## 8. 页面语言

- 导航：保留消息、通讯、AI 任务、待办、设置；管理仅管理员可见。品牌标志不伪装为按钮。
- 消息：会话列表、聊天正文、输入区使用连续 surface；当前会话必须有明确选中态。
- 通讯录：联系人和群聊共享统一资料框架，状态靠近头像/名称。
- AI 任务：使用紧凑列表行；任务名优先，范围、发起者和时间为次级信息。
- 待办：使用连续列表与分组分隔；完成控件、任务名和截止时间优先，来源与优先级作为次级信息；详情在宽屏停靠、窄屏覆盖。
- 设置：按个人资料、外观、连接与快捷键、诊断与隐私、账户操作分组；退出登录不做全宽主按钮。
