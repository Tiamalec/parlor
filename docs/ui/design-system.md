# Parlor V2 UI Design System

状态：2026-11-25「会客厅」重设计基线。此后新增页面、组件和主题调整以本文件为准；旧截图与旧蓝灰 token 只作为历史记录保留。服务端 Web 管理台共享视觉语言，但使用独立 CSS 变量，不接入 Qt ThemeManager。

## 0. 视觉方向

Parlor 是供人和 AI 长时间协作的桌面聊天室。新基线把界面视为一间安静的会客厅：暖象牙纸面、深森林绿主操作、暖紫褐 Agent 标识、衬线标题与无衬线正文。目标是让消息、人物、任务和当前操作清楚，同时保留一点品牌气质。

- 每个页面只设一个视觉中心和一个主要操作。
- 内容少时用真实空状态收住版面，不用空白大面板假装布局完整。
- 相邻内容共享背景、对齐线和间距；边框只用于确有必要的交互或浮层。
- 品牌名统一为 **Parlor**，标志几何不变，运行时配色使用 `text_primary` / `agent` / `brand_panel`。
- 任何页面缩小到 720px 截图后，标题、主要内容、次级信息和主操作仍应按顺序可读。

### 判废条件

任一条仍成立，本轮视觉不算完成：

- 页面仍像默认 Qt 控件排版，或空白容器占据主体。
- 到处是描边小卡片，或在普通内容里 Surface 套 Surface。
- 蓝色、紫色或金色同时抢主操作。
- 11–12px 元数据承担主要信息。
- 状态只靠颜色，或图标按钮缺少 tooltip、accessibleName、焦点态。
- 滚动区域与内容背景角色不一致，暗色下露白。

## 1. 设计原则

1. 安静、现代、可靠，优先保障长时间聊天和任务扫描的可读性。
2. 使用少量连续表面层级，不用深浅底板拼接制造层级。
3. 列表优先使用行、分隔线和选中态；卡片只用于独立对象、表单分组或浮层。
4. 深森林绿表示主要操作与选择；暖紫褐只用于 AI/Agent 语义；不要用第二种主色争夺主要操作。
5. 所有状态同时使用文字与形状/图标，颜色不作为唯一信息载体。
6. 标题用衬线建立气质，正文和控件用系统无衬线保证可读性和跨平台稳定。

## 3. 表面层级

- `canvas`：页面背景，不放边框或阴影。
- `surface`：聊天主区、会话栏、输入区、设置分组、待办工作区。相邻 surface 优先用 1px 分隔线，不套多层卡片。
- `surface_subtle`：hover、选中、表头和局部分组，不作为大面积独立底板。
- `surface_elevated`：菜单、对话框、详情浮层。默认使用强边框；只在必要浮层使用一次轻量 `QGraphicsDropShadowEffect`。
- `overlay_scrim`：只用于模态/抽屉，不改变底层业务状态。

`QScrollArea`、其 viewport 与内容 QWidget 必须声明同一表面角色，禁止依赖系统 palette 或透明背景偶然透出父组件。

## 4. 字体与图标

- 标题字体栈：`Iowan Old Style`、`Palatino Linotype`、`Songti SC`、`STSong`、`Noto Serif CJK SC`、`Source Han Serif SC`、`SimSun`，最终回退系统衬线。
- 正文字体栈：`PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei UI`、`Noto Sans CJK SC`、`system-ui`、`sans-serif`。
- 等宽字体栈：`SF Mono`、`Menlo`、`Consolas`、`Liberation Mono`、`monospace`。
- 不捆绑新字体；中文由系统字体回退处理。

## 5. 尺寸、间距与圆角

- 间距标尺：4、8、12、16、24、32、40px。
- 页面外边距：宽屏 24px，紧凑窗口 16px。
- 控件高度：紧凑 28px，默认 36px，主操作 40px；导航行 40px。
- 列表行：通讯录 56px、任务/待办 64px、会话 72px。
- 圆角：小型元素 6px、控件 8px、面板/消息 12px、弹窗/浮层 16px。
- 不新增 16px 以上的大圆角容器；头像例外，保持圆形。
- 边框统一 1px；焦点态使用 2px `primary` 边界并保证控件外尺寸稳定。

## 6. 布局与导航

| 窗口宽度 | 侧栏 | 内容 |
| --- | --- | --- |
| `720–899` | 64px 图标栏 | 16px 边距；聊天与通讯录单页切换；详情覆盖 |
| `900–1179` | 76px 图标栏 | 16–24px 边距；聊天 `<1040px` 单页切换 |
| `≥1180` | 236px 文字侧栏 | 24px 边距；会话栏 300–360px |

- 侧栏包含品牌字标、工作台导航、未读标记、当前账号和固定底部设置入口。
- 导航顺序：消息、通讯、AI 任务、待办、管理（仅管理员）、设置。
- 聊天详情面板只在聊天正文宽度 ≥1000px 时停靠，否则使用覆盖层。
- 设置内容最大宽度 760px；AI 任务列表最大内容宽度 1100px。
- 通讯录保持左侧目录 + 右侧资料；窄屏切换为单页。

## 7. 页面语言

- **登录**：左侧深森林绿品牌区，右侧暖象牙表单面板。标题使用衬线，说明保持短句；窄屏隐藏品牌区。
- **消息**：会话列表、聊天正文和输入区使用连续表面；当前会话使用浅绿底和左侧指示条。
- **通讯录**：联系人和群聊共享统一资料框架，状态靠近头像/名称；空详情落在画布上，不包装成巨大卡片。
- **AI 任务**：页面头、Agent 状态、筛选栏和紧凑任务行；任务名优先，范围、发起者和时间为次级信息。
- **待办**：连续列表与分组分隔；完成控件、任务名和截止时间优先；详情宽屏停靠、窄屏覆盖。
- **设置**：左侧分类导航，右侧分组与分隔线；主题和密度使用紧凑选择器；退出登录放入独立危险操作区。
- **管理**：指标行、只读目录和审计表格；保持只读与脱敏边界。

## 8. 交互状态

所有可交互控件必须定义：default、hover、pressed、focus-visible、checked/selected、disabled、error。

- 选中项使用背景 + 文字/图标变化；侧栏额外保留稳定形状指示。
- 危险操作使用 `danger` 文字/边框，确认按钮才使用实色危险背景。
- 状态徽标必须包含文本，不使用纯色圆点作为唯一状态。
- 图标按钮必须有 tooltip、accessible name 和键盘焦点。

## 9. 截图验收

- 每页至少覆盖 720×520、860×600、1180×760、1440×900 四档宽度，浅色与深色各一组。
- 关键状态：空、加载、错误、超长文本、无权限、键盘焦点。
- 截图由 `tools/ui_snapshot.py` 生成，输出到 `docs/ui/screenshots/baseline-2026-11/`。
- 旧截图归档到 `docs/ui/screenshots/archive-2026-11/`，不得作为新页面模板。
- 未实际运行的平台标记为未验证；功能测试通过不能代替视觉验收。
