# 运行、测试与演示

## 1. 环境准备

| 组件 | 要求 |
| --- | --- |
| Python | 3.10+，建议 3.11+ |
| 服务端 | 只依赖标准库 |
| V2 客户端 | `PySide6>=6.7,<7` |
| 数据库 | SQLite（标准库） |
| 模型（可选） | Ollama + `chatroom-qwen3.5-4b`，或管理台配置的云端模型 |

```bash
python -m pip install -r requirements.txt
```

从项目根目录执行所有命令。不要提交 `.env`、`data/`、日志和模型密钥。

## 2. 启动

### 2.1 服务端

```bash
python -m server
```

默认监听 `127.0.0.1:8765`，管理台为 `http://127.0.0.1:8766`。

### 2.2 三个客户端

分别打开三个终端，每个终端执行：

```bash
python -m client
```

注册三个不同用户名，例如 `alice`、`bob`、`carol`。不要共用用户名，否则在线状态和会话归属无法用于验收。

### 2.3 本地模型（可选）

```bash
ollama pull qwen3.5:4b
ollama create chatroom-qwen3.5-4b -f ollama/Modelfile
ollama run chatroom-qwen3.5-4b
```

模型不可用时，服务端仍可启动，注册、登录、私聊和群聊不受影响；Agent 请求会返回受控错误。

### 2.4 局域网演示（可选）

服务端 `.env`：

```text
CHAT_HOST=0.0.0.0
```

客户端：

```text
CLIENT_HOST=<服务端局域网 IP>
```

只在可信局域网使用，不要把聊天端口或管理端口直接暴露到公网。

## 3. 15 分钟演示脚本

### 0–2 分钟：团队与架构

- 说明 C/S 结构、TCP 长度前缀协议、SQLite 持久化和 Agent 工具链路。
- 说明三个客户端分别由谁操作。

### 2–5 分钟：基本聊天

1. 三个客户端分别注册并登录。
2. 展示在线用户列表。
3. `alice` 与 `bob` 私聊，发送文字。
4. 展示已读、输入状态和消息持久化。

### 5–7 分钟：群聊与媒体

1. `alice` 创建群聊并邀请 `bob`、`carol`。
2. 发送群消息，确认三端广播。
3. 发送图片或表情包，展示消息展示与自己的撤回。
4. 打开历史搜索，搜索刚才的关键词。

### 7–9 分钟：断线与重连

1. 关闭其中一个客户端，其他两端看到离线状态。
2. 在离线期间向该用户发送消息。
3. 重新启动客户端并登录，展示离线消息同步。

### 9–13 分钟：Agent 主链路

1. 在群聊中发送 `@Agent 总结一下最近的讨论`。
2. 展示服务端读取当前会话记录、模型生成结果、结果回写原会话。
3. 发送 `@Agent 提取今天的待办`，展示结构化待办卡片。
4. 打开 AI 任务中心或工具审计，展示真实工具调用记录、参数和状态。
5. 将一条待办加入个人待办，展示完成和版本校验。

### 13–14 分钟：扩展功能

按时间选择展示：

- 禁言与解除。
- 撤回时限和越权拒绝。
- Agent 定时总结。
- 服务端 Web 搜索工具。
- 模型离线时聊天仍正常。

### 14–15 分钟：总结

- 说明已实现的需求和两个以上自定义功能。
- 说明当前限制：未在 Windows/Linux 实机验收，公网部署需要 TLS 和限流。
- 说明测试结果和复现命令。

## 4. 录屏清单

录屏前：

- 关闭包含密钥的终端输出、编辑器标签和浏览器页面。
- 清空或使用演示数据目录，避免展示真实聊天内容。
- 确认三个客户端窗口和终端都在画面内，字号可读。

录屏必须出现：

- 服务端启动命令和监听地址。
- 三个客户端在线。
- 私聊和群聊各一条消息。
- 一个客户端异常退出并重连，离线消息补发。
- 群聊 @Agent 的完整请求与回复。
- 工具调用记录界面。
- 至少一个自定义扩展。

建议额外录制：

- 完整测试命令与结果。
- 管理台模型配置（不展示 API Key）。

## 5. 常见问题

| 现象 | 检查 |
| --- | --- |
| 客户端连接失败 | 服务端是否启动；`CLIENT_HOST`、`CHAT_PORT` 是否一致 |
| Agent 无响应 | Ollama 是否运行；模型名是否与管理台配置一致；查看服务端日志 |
| 图片发送失败 | 文件大小、MIME 和文件签名是否受支持 |
| 管理台打不开 | 是否在服务端本机访问 `127.0.0.1:8766`；Cookie/CSRF 配置是否正确 |
| 数据异常 | 停止服务端后再备份或恢复 `chatroom.sqlite3` 与 `uploads/` |
