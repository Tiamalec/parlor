PARLOR · LOGO GUIDELINES

Parlor — Logo 使用规范

一间房，一个 Agent 席位。安静、现代、可靠，16px 仍能辨认。

不是多了一个 AI 功能，而是房间里多了一个 Agent 成员。

外层是共享房间与对话尾巴，内层实心气泡是 Agent 席位。Ink 让房间保持安静，Agent 紫只落在成员身上；单色与反白都不依赖第二种颜色。

字标使用 Avenir Next Demi Bold 转曲，已做收紧密排；文件内不含 live text。
