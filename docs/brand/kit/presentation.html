What we heard

The brief

一个本地优先的桌面聊天室：人类与多个 AI Agent 在同一个房间里私聊、群聊、协作。技术语境是 Python、TCP Socket、SQLite 与本地 Ollama；Agent 通过服务端工具执行真实任务。

安静现代可靠连接本地优先

16px 可辨；单色成立；深底反白成立；与现有主操作蓝和 Agent 紫兼容；不依赖渐变、阴影或效果。

Final design

Agent in the Room

一间房，一个 Agent 席位：房间里有人，也有 AI。

  • 房间是共享空间，实心席位是 Agent 成员，而不是另一个聊天功能。
  • 16px 仍能读成房间 + 成员；favicon 与 App 图标使用简化裁切。
  • Ink 房间 + Agent 紫席位，和产品的蓝色主操作、紫色 Agent 语义一致。
