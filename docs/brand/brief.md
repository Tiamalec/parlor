## 1. 项目与品牌

- 品牌名：`Parlor`（曾用名 `AI Agent`），中文描述：`智能聊天室`。
- 产品：本地优先的桌面聊天室，人类与多个 AI Agent 在同一个房间里私聊、群聊、协作。
- 技术语境：Python、TCP Socket、SQLite、本地 Ollama；Agent 通过服务端工具执行真实任务。
- 主要受众：课程验收老师与同学、关注本地 AI 的开发者、潜在开源使用者。
- 使用场景：登录页 46px 品牌方块、窗口/托盘图标、favicon、README 与 GitHub 头像、演示封面、深浅色背景。

## 2. 品牌形容与边界

形容词：**安静、现代、可靠、连接、智能但不喧闹**。

必须成立的条件：

- 16px 仍能辨认；一个颜色仍成立；深底反白仍成立。
- 与现有语义色兼容：主操作蓝 `#356AE6`，Agent 紫 `#6B4FD3`。
- 适合放在圆角方形品牌块里，也能独立作为符号使用。

明确避开：

- 机器人头、默认 Sparkles、紫色渐变、彩色渐变、盾牌、地球、上行箭头。
- 没有转折的普通聊天气泡；把“产品”直接画出来的字面图形。
- 细线、微小缺口、少于画布 1/48 的细节。

## 3. 品类研究

参考库检索结果（1,432 个真实标志）：

- `social-communication`：61 个；蓝色 39.3%，圆形 37.7%，containment 41%，negative-space 24.6%，speech-bubble 24.6%。
- `developer-tools`：295 个；multi 27.8%，蓝色 19.3%，containment 34.2%，negative-space 19%，gradient 12.9%。
- 全库颜色中位数 2 个，75% 不超过 3 色；渐变仅 19%。

品类惯例（默认视为需要避开或改造的俗套）：聊天气泡、@ 符号、网络节点、机器人、Sparkles、蓝紫渐变、圆角方形 App 图标。

## 4. 词图与策略

词图交点：**房间 / 席位 / 门 / 声音 / 回应 / 连接**。

策略：不做“AI 魔法”，做“一个有 Agent 成员在里面的房间”。标志先是一个容器，再是一个对话；先安静，再有一点巧思。

## 5. 长名单（12 个一句话概念）

1. 一间房，门口就是说话的气泡。
2. 两个声部共用一条 A 的斜画。
3. 房间轮廓里坐着一个 Agent 席位。
4. 一大一小两个气泡，在同一场对话里。
5. 房门被画成对话的尾巴。
6. @ 的负空间藏在一间房里。
7. 三条消息线，其中一条穿出房间。
8. 两个房间在角上重叠，交集是对话。
9. 一个文本光标，同时是气泡的尾巴。
10. 圆桌俯视图，一个席位是实心的。
11. 方括号组成房间，右括号变成尾巴。
12. 字母 A 的负空间是一间房。

## 6. 入围三案

### A — Two Voices A（字标型）

两道对话的笔画构成 A，名字本身就是标志。16px 最稳，适合作为头像与字标的核心。

风险：单字母标志较常见；需要靠字重、开口和横画比例建立识别度。

### B — Agent in the Room（推荐，组合/抽象型）

一间房，一个 Agent 席位：外层是房间与对话尾巴，内层是一个更小的气泡。房间里有人，也有 AI。

风险：16px 时内层细节会简化成一个实心块，需要单独的 favicon 小尺寸版本；外层尾巴在极小尺寸下会变弱。

### C — Exchange（图形型）

一大一小两个气泡，人类与 Agent 在同一场对话里。最直接表达“聊天”，也最有表情。

风险：双气泡是聊天品类的强惯例，需要靠大小差与尾巴方向建立区别；16px 时两个形状略忙。

## 7. 自测记录

- `Two Voices A`：`svg_audit.py` 96/100；唯一提示是描边尚未转填充，最终母版需展开为轮廓。
- `Agent in the Room`：`svg_audit.py` 98/100；无失败项；16px 可读为“房间 + 一个成员块”。
- `Exchange`：`svg_audit.py` 90/100；一条 30.5° 近角线需要收到 30°；16px 两个气泡仍可区分。
- 三案均在 512px 白底与 16px 像素放大图中检查；未做真实设备 Retina 与打印介质验证。
